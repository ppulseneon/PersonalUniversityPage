1. Установка

При разработке Python-скриптов с использованием pycatia рекомендуется выполнить описанные ниже действия. Готовые сборки доступны на странице выпусков проекта.

Краткий вариант

Предполагается, что Python 3.9 или более поздняя версия уже установлен и вы знаете, как и когда пользоваться виртуальными окружениями. На практике их следует использовать постоянно.

Можно установить pycatia из PyPI с помощью pip либо клонировать репозиторий GitHub. Не применяйте оба способа в одной структуре каталогов.

Установка из PyPI:

pip install pycatia

Обновление установленной версии:

pip install pycatia --upgrade

Получение актуальной версии ветки master из GitHub:

git clone https://github.com/evereux/pycatia.git
# Перейдите в каталог клонированного проекта.
cd pycatia
# Создайте виртуальное окружение Python.
python -m virtualenv env
# Активируйте виртуальное окружение.
env\Scripts\activate
# Установите зависимости pycatia.
pip install -r requirements\requirements.txt

Подробный вариант

У конечного пользователя pycatia может не быть прав администратора на рабочем компьютере. В этом случае для установки Python и модуля virtualenv потребуется помощь человека с соответствующими правами.

Загрузите Python 3 версии 3.9 или новее с python.org и установите его. При установке обязательно включите добавление Python в переменные окружения.

Установите virtualenv из командной строки, запущенной от имени администратора:

python -m pip install virtualenv

Создание виртуального окружения

Виртуальное окружение позволяет устанавливать пакеты Python изолированно от основной установки Python. Создайте каталог для скриптов pycatia, например c:\Users\<username>\python\pycatia-scripts, и перейдите в него:

cd c:\Users\<username>\python\pycatia-scripts

Создайте и активируйте окружение:

python -m virtualenv env
env\Scripts\activate

После активации приглашение командной строки должно выглядеть примерно так:

(env) c:\Users\<username>\python\pycatia-scripts>

Установите pycatia:

python -m pip install pycatia

Установка завершена. Перед запуском скриптов pycatia необходимо активировать это виртуальное окружение.

Проверка установки

Важно сначала запустить сеанс CATIA V5. Затем откройте командную строку CMD и активируйте виртуальное окружение, если оно ещё не активно. Введите python, чтобы перейти в интерактивный интерпретатор.

Импортируйте объект приложения CATIA:

from pycatia import catia
application = catia()
help(application)
# Нажмите q, чтобы выйти из справки.
# Откройте новый CATPart.
documents = application.documents
documents.add('Part')

Для выхода из интерпретатора:

exit()

Если сообщений об ошибках нет, но новый CATPart не появился, проверьте в диспетчере задач, не работают ли скрытые процессы CATIA или CNEXT. Иногда при установке CATIA V5 COM-объект регистрируется некорректно. Если приведённый пример не работает, может потребоваться переустановка CATIA V5 или регистрация её COM-сервера.

Регистрация COM-сервера CATIA V5

Обычно регистрация выполняется автоматически при установке CATIA V5, но иногда этот этап завершается неудачно. Из командной строки перейдите в каталог, содержащий cnext.exe той установки CATIA V5, которую требуется зарегистрировать. Например:

cd <drive>\<CATIA_DIR>\<CATIA_VERSION>\code\bin

Замените <env_file> и <path_to_env_file> соответствующими значениями и выполните:

cnext.exe /regserver -env <env_file> -direnv <path_to_env_file>

После этого можно перейти к началу работы с pycatia.

2. Начало работы

Прежде чем продолжить знакомство с pycatia, установите библиотеку. Перед выполнением вводных примеров на этой странице необходимо запустить CATIA V5 и открыть командную строку CMD. Окружение, в котором установлена pycatia, должно быть активировано до запуска интерпретатора Python.

Открытие нового CATPart

Почти всегда требуется импортировать объект приложения catia или CATIADocHandler.

from pycatia import catia
from pycatia.mec_mod_interfaces.part_document import PartDocument

# Инициализируйте приложение автоматизации CATIA.
# CATIA V5 уже должна быть запущена.
application = catia()
documents = application.documents

documents — экземпляр класса Documents.

part_document: PartDocument = documents.add('Part')

Метод add коллекции Documents принимает строку 'Part', 'Product' или 'Drawing'. Вызов documents.add('Part') добавляет новый CATPart в коллекцию документов и возвращает объект документа — в данном случае PartDocument.

Объект документа имеет ряд доступных свойств:

part_document.name
# Возвращает имя нового документа.
part_document.path
# Возвращает объект pathlib.Path для документа.

Создание геометрического набора

Геометрический набор создаётся с помощью коллекции HybridBodies. Ваша конфигурация CATIA может автоматически создавать такой набор в новом CATPart; тем не менее в этом примере мы создадим ещё один.

part = part_document.part
hybrid_bodies = part.hybrid_bodies
new_set = hybrid_bodies.add()
new_set.name
# Возвращает имя нового набора.
# Чтобы переименовать набор:
new_set.name = 'Construction Geometry'

О запуске скриптов см. Create And Run A Script. Более подробные примеры взаимодействия с pycatia приведены в разделе Examples, содержащем скрипты для выполнения в терминале.

Примечание оригинала. CATIADocHandler предназначен для случаев последовательного открытия и закрытия нескольких документов. Примеры его использования приведены в разделе Examples.
