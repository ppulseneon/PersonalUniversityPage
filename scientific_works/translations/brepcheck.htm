1. Описание класса

BRepCheck_Analyzer — средство проверки общей корректности геометрической формы. Чтобы форма считалась корректной в Open CASCADE, она и составляющие её подформы должны удовлетворять определённым критериям. Их проверяет функция IsValid. После определения корректности можно диагностировать отдельные аномалии и исправить их средствами пакетов ShapeAnalysis, ShapeUpgrade и ShapeFix.

Заголовочный файл:

#include <BRepCheck_Analyzer.hxx>

2. Конструктор и инициализация

Конструктор BRepCheck_Analyzer

BRepCheck_Analyzer(
    const TopoDS_Shape& S,
    const bool GeomControls = true,
    const bool theIsParallel = false,
    const bool theIsExact = false
)

Создаёт объект проверки формы S. Если GeomControls равно false, проверяется только топологическая информация. Геометрические проверки включают:

  • для вершины — BRepCheck_InvalidToleranceValue, ещё не реализовано (NYI);
  • для ребра — BRepCheck_InvalidCurveOnClosedSurface, BRepCheck_InvalidCurveOnSurface, BRepCheck_InvalidSameParameterFlag, а также BRepCheck_InvalidToleranceValue, ещё не реализовано;
  • для грани — BRepCheck_UnorientableShape, BRepCheck_IntersectingWires, а также BRepCheck_InvalidToleranceValue, ещё не реализовано;
  • для контура — BRepCheck_SelfIntersectingWire.

Init

void Init(
    const TopoDS_Shape& S,
    const bool GeomControls = true
)

S — проверяемая форма. При GeomControls = false проверяется только топология. В описании Init оригинал перечисляет те же категории геометрических проверок: для вершины — некорректный допуск (NYI); для ребра — некорректные кривые на поверхности и замкнутой поверхности, некорректный флаг SameParameter и допуск (NYI); для грани — невозможность согласованной ориентации, пересечение контуров и некорректный допуск (NYI); для контура — самопересечение. Для ошибок допуска в этом описании используется написание BRepCheck_InvalidTolerance.

3. Проверка корректности

IsValid без аргументов

bool IsValid() const

Возвращает true, если в форме S и её подформах не обнаружены дефекты. Проверяется корректность топологии и, в частности, параметризации рёбер.

Для корректности топологии должны выполняться следующие условия:

  • Если ребро не является вырожденным, у него должно быть не менее двух вершин. Вершины должны лежать в пределах ограничивающих рёбер с учётом допуска, заданного в вершине.
  • Рёбра должны принадлежать хотя бы одной грани. Их представления должны удовлетворять назначенному им допуску.
  • Контуры, определяющие грань, должны быть замкнутыми и не должны самопересекаться.
  • Внутри грани должен существовать один контур, охватывающий все остальные.
  • Ориентация контуров должна быть согласована с каждым из рёбер.
  • Грани должны быть правильно ориентированы, в частности относительно соседних граней, если они задают твёрдое тело.
  • Оболочки, ограничивающие твёрдое тело, должны быть замкнутыми. Для твёрдого тела должна существовать одна внешняя охватывающая оболочка.

Параметризация ребра проверяется одним из двух способов в зависимости от контекста. Если ребро является отдельным объектом либо рассматривается в составе контура или составного объекта, его параметризация определяется трёхмерной кривой и считается корректной.

Если ребро рассматривается в контексте грани, флаги SameParameter и SameRange должны иметь значение true. Для их проверки используются функции BRep_Tool::SameParameter и BRep_Tool::SameRange. Если хотя бы один флаг равен false, ребро признаётся некорректным без дополнительных проверок.

Когда оба флага установлены, IsValid проверяет, согласовано ли представление ребра на поверхности грани с трёхмерной параметризацией в пределах допуска ребра. Пусть C — трёхмерная кривая, P — параметрическая кривая PCurve на базовой поверхности S, а t — параметр. Проверяется условие:

|C(t) − S(P(t))| ≤ tolerance,

где tolerance — допуск, сохранённый в ребре.

IsValid для подформы

bool IsValid(const TopoDS_Shape& S) const

Здесь S — подформа исходной формы. Метод возвращает истинное значение, если в ней и во всех её подформах не обнаружены дефекты.

4. Выбор метода и параллельный режим

SetExactMethod

void SetExactMethod(const bool theIsExact)

Задаёт способ вычисления расстояния. При theIsExact = false расстояние вычисляется в конечном числе точек: это быстрее, но результат может оказаться некорректным. При theIsExact = true применяется более медленный, но более точный метод на основе класса BRepLib_CheckCurveOnSurface.

Точный метод используется только для рёбер с признаком SameParameter. По умолчанию применяется вычисление в конечном числе точек.

IsExactMethod

bool IsExactMethod()

Возвращает true, если выбран точный метод.

SetParallel

void SetParallel(const bool theIsParallel)

Устанавливает флаг параллельного выполнения.

IsParallel

bool IsParallel()

Возвращает true, если установлен флаг параллельного выполнения.
