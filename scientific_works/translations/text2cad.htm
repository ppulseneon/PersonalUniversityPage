Аннотация

Создание прототипов сложных моделей в современных системах автоматизированного проектирования (САПР) может занимать много времени. Одна из причин — отсутствие интеллектуальных систем, способных быстро создавать более простые промежуточные детали. Мы предлагаем Text2CAD — первую систему искусственного интеллекта для генерации параметрических CAD-моделей по тексту, использующую понятные проектировщику инструкции для пользователей с разным уровнем подготовки. Кроме того, мы представляем конвейер разметки данных, который с помощью Mistral и LLaVA-NeXT формирует для набора DeepCAD текстовые запросы на естественном языке. Набор содержит 170 тысяч моделей и 660 тысяч текстовых аннотаций: от отвлечённых описаний формы, например «создайте два концентрических цилиндра», до подробных инструкций по построению. В рамках Text2CAD мы предлагаем сквозную авторегрессионную сеть на основе трансформера для генерации параметрических CAD-моделей по входному тексту. Качество оценивается по совокупности показателей, включая визуальное качество, точность параметров и геометрическую точность. Предлагаемая система демонстрирует потенциал применения в проектировании с поддержкой искусственного интеллекта.

1. Введение и постановка задачи

Автоматизированное проектирование играет важную роль в промышленном дизайне и аддитивном производстве. Создание прототипов требует моделирования деталей на основе конструктивных элементов, точных измерений и редактирования на разных стадиях проектирования. Хотя итоговая модель сохраняется в граничном представлении B-rep, процесс её создания часто состоит из цепочки двумерных эскизов — окружностей, отрезков, сплайнов — и трёхмерных операций, таких как выдавливание, построение по сечениям и скругление. Такое представление позволяет управлять историей построения и последовательно уточнять модель.

Современные CAD-инструменты обладают широкими возможностями, однако в них недостаточно интегрированы средства проектирования с помощью искусственного интеллекта. Система, способная получать параметрические модели из текстовых описаний, могла бы помогать собирать сложные трёхмерные объекты. Каталоги готовых деталей поддерживают повторное использование существующих моделей, но не решают задачу генерации последовательности построения по описанию проектного замысла.

Мы предлагаем Text2CAD для генерации параметрических CAD-моделей, представленных последовательностями построения: параметрами двумерных эскизов и операций выдавливания. Решение требует преодолеть две основные трудности: отсутствие подходящего набора данных и необходимость построить сеть, отображающую текст в последовательность CAD-операций. Для этого мы создаём текстовые описания моделей DeepCAD с помощью открытых больших языковых и визуально-языковых моделей. Аннотации охватывают несколько уровней подробности — от выражений «длинный прямоугольный объект» или «тонкий S-образный объект» до точных параметрических указаний. Инструкции могут содержать арифметические зависимости и численные выражения.

Существующие методы генерации трёхмерных объектов по тексту не решают эту задачу непосредственно: их результат обычно не является параметрическим и не допускает привычного для проектировщика редактирования. Получение скрипта с помощью универсальной языковой модели также не равнозначно восстановлению последовательности промежуточных эскизов и выдавливаний. Визуально-языковые модели могут неверно интерпретировать техническую форму: например, описать два концентрических полых цилиндра названием бытового предмета. В Text2CAD мы используем ответы языковых и визуально-языковых моделей для создания крупного массива аннотаций, на котором обучается предметная мультимодальная сеть.

Основные результаты работы — система генерации параметрических CAD-моделей по тексту, конвейер разметки с различной сложностью и подробностью инструкций и сквозная авторегрессионная архитектура, восстанавливающая историю построения. Эксперименты показывают преимущество перед двухэтапным базовым методом, адаптированным для этой задачи.

2. Разметка данных Text2CAD

Конвейер формирует аннотации DeepCAD, описывающие процесс построения в понятной человеку форме. Он состоит из двух стадий: получения обобщённых описаний формы с помощью визуально-языковой модели и создания текстовых инструкций разной подробности с помощью языковой модели на основе этих описаний и сведений о построении.

Описания формы с помощью визуально-языковой модели

Сначала LLaVA-NeXT формирует отвлечённые описания объектов. Задача состоит в том, чтобы передать структуру трёхмерной формы, например «кольцеобразная конструкция», «цилиндр» или «шестиугольник с цилиндром сверху». Описания создаются как для итоговой CAD-модели, так и для её промежуточных частей. Для каждой части и всей модели получают изображения с заранее заданных направлений, после чего передают их LLaVA-NeXT вместе с подготовленным запросом.

Многоуровневые инструкции с помощью языковой модели

На следующей стадии Mixtral-50B создаёт несколько аннотаций, отличающихся подробностью описания. Последовательности построения DeepCAD представлены в формате JSON. Генератор минимальных метаданных предварительно обрабатывает их: случайные бессодержательные ключи заменяются понятными обозначениями, например part_1 и loop_1. Это снижает склонность языковой модели к галлюцинациям. Минимальные метаданные дополняются описаниями отдельных частей и всей формы, полученными от визуально-языковой модели.

По этим данным сначала создаются подробные инструкции на естественном языке с минимальной потерей сведений. Затем языковая модель перерабатывает их в инструкции нескольких уровней, используя запрос с примерами:

  • L0 — абстрактный уровень. Обобщённое описание итоговой формы, полученное на первой стадии.
  • L1 — начальный уровень. Упрощённое изложение шагов проектирования без сложных измерений и специальной терминологии; рассчитано на неспециалистов и ранние стадии проектирования.
  • L2 — промежуточный уровень. Обобщённое геометрическое описание, сочетающее понятность с технической точностью.
  • L3 — экспертный уровень. Подробное геометрическое описание с относительными размерами для пользователей, которым требуется глубокое понимание построения или непосредственное выполнение моделирования.

Можно было бы создавать многоуровневые инструкции непосредственно из минимальных метаданных, пропуская подробное описание. Однако в наших наблюдениях это увеличивало число галлюцинаций и неточностей. Поэтапное формирование инструкций позволяет уменьшить эти затруднения.

3. Архитектура трансформера Text2CAD

Трансформер преобразует описание на естественном языке в трёхмерную CAD-модель, авторегрессионно восстанавливая промежуточные шаги построения. Для текстового запроса T модель обучается условному распределению вероятностей последовательности C:

P(C | T) = ∏t=1…Nc P(ct | c1:t−1, T; θ).

Здесь Nc — число токенов CAD-последовательности, а θ — обучаемые параметры. Последовательность содержит токены эскизов и выдавливаний. Токен задаёт двумерные координаты примитивов, параметры выдавливания — углы Эйлера, вектор переноса, расстояния выдавливания, булеву операцию или масштаб эскиза — либо служебный признак начала или завершения кривой, контура, грани, эскиза, выдавливания и всей последовательности. Непрерывные координаты и параметры квантуются с точностью 8 бит, что даёт 256 классов.

Кодирование текста и адаптивный слой

Текст пользователя может варьироваться от простого описания до подробных экспертных команд. Для получения контекстных представлений мы применяем предварительно обученный BERT. Обучаемый адаптивный слой, состоящий из одного слоя кодировщика трансформера, уточняет эти представления с учётом лексики и структуры CAD-инструкций:

Tembed = BERT(T);   Tadapt = AdaptiveLayer(Tembed).

Кодирование CAD-последовательности

Каждый двумерный токен сначала представляется двумя векторами унитарного кодирования размерности 256. Начальное представление CAD-последовательности получается суммированием обучаемых представлений двух компонент и позиционного кодирования:

F0 = CoxWx + CoyWy + P.

Послойное перекрёстное внимание

Мы используем стандартный декодировщик трансформера с послойным перекрёстным вниманием между представлениями CAD и текста. Каждый блок сначала применяет многоголовое самовнимание к CAD-последовательности. Текстовые представления проецируются в пространство нужной размерности. Запросы Q формируются из CAD-представлений, а ключи K и значения V — из текстовых:

Q = FWQ;   K = TadaptlWK;   V = TadaptlWV;
A = Softmax(QK⊤ / √dk)V.

Перекрёстное внимание позволяет динамически менять значимость частей текста относительно текущего состояния CAD-последовательности. После него применяются dropout, нормализация слоя и сеть прямого распространения. Повторение блоков обеспечивает более глубокое согласование текста и CAD-токенов. Итоговые представления передаются многослойному перцептрону, предсказывающему выходную последовательность. При обучении используется перекрёстная энтропия.

4. Эксперименты

Мы используем DeepCAD, содержащий приблизительно 150 тысяч обучающих последовательностей и примерно по 8 тысяч последовательностей для тестирования и валидации в формате «эскиз — выдавливание». Эскизы и итоговые модели нормализуются в единичном ограничивающем параллелепипеде. Для каждого объекта формируются четыре запроса уровней L0–L3, что даёт около 600 тысяч обучающих примеров и примерно по 32 тысячи примеров для тестирования и валидации.

Трансформер содержит восемь блоков декодировщика с восемью головами самовнимания. Оптимизатор — AdamW, скорость обучения — 0,001, dropout — 0,1. Максимальная длина текста — 512 токенов, CAD-последовательности — 272 токена. Размерность представлений BERT и адаптивного слоя равна 1024, CAD-представлений — 256. В первых двух блоках не применяется перекрёстное внимание. Обучение с подстановкой правильных предыдущих токенов выполняется в течение 160 эпох на одной NVIDIA A100 с 80 ГБ памяти и занимает два дня. При выводе используется выбор одного наиболее вероятного токена.

В качестве базовых методов рассматриваются DeepCAD, адаптированный к текстовому вводу, и Text2CAD без адаптивного слоя. Для DeepCAD адаптивный слой обучается отображать представления BERT в эталонный скрытый вектор, который затем передаётся предварительно обученному декодировщику. В варианте Text2CAD без адаптивного слоя представления BERT поступают прямо в декодировщик трансформера.

Оценка последовательностей

Мы оцениваем соответствие параметров предсказанной CAD-последовательности входному тексту и визуальное соответствие восстановленной модели. Показатели CLIP, используемые в генерации трёхмерных объектов по тексту, могут недостаточно полно отражать геометрические и параметрические особенности CAD. Поэтому используются отдельные показатели параметрической и геометрической точности.

Сравнение последовательностей проводится для экспертных запросов L3: они наиболее подробно определяют эталонную историю построения. Предсказанные и эталонные контуры одного эскиза сопоставляются венгерским алгоритмом. Затем вычисляются F1 для примитивов и выдавливаний, расстояние Чамфера (CD) между геометриями и доля некорректных CAD-последовательностей (IR).

Оценка GPT-4V и исследование с участием пользователей

Для визуальной оценки GPT-4V получает текст и изображения моделей DeepCAD и Text2CAD с нескольких направлений. Она выбирает модель, лучше соответствующую описанию формы и геометрии, либо возвращает ответ «не определено». Для каждого уровня случайно отбирается 1000 тестовых примеров.

В пользовательском исследовании участвуют пять CAD-проектировщиков с разным опытом. Каждый оценивает по 20 примеров на уровень, выбирая более геометрически точную модель, которую проще отредактировать до желаемого результата. Характер предпочтений сходен с оценкой GPT-4V: более заметное преимущество Text2CAD наблюдается для подробных запросов L2 и L3.

5. Ограничения

Несмотря на перспективные результаты, система имеет ограничения. LLaVA-NeXT чувствительна к перспективным искажениям изображений, что влияет на описание формы и итоговые текстовые запросы. Отсутствие стандартизованных тестов генерации CAD по тексту затрудняет всестороннюю оценку. Кроме того, DeepCAD несбалансирован: в нём преобладают прямоугольные и цилиндрические формы, что ограничивает устойчивость модели при работе с более сложными объектами.

6. Заключение

Мы представили Text2CAD — систему генерации параметрических CAD-моделей по текстовым запросам для пользователей разного уровня подготовки. Она объединяет двухэтапную разметку с помощью языковой и визуально-языковой моделей и сквозную обучаемую архитектуру трансформера, преобразующую инструкции в последовательности CAD-операций. Оценка GPT-4V и исследование с участием проектировщиков показывают преимущество над двухэтапным базовым методом, особенно при увеличении сложности и подробности запросов. Дальнейшая работа будет направлена на уменьшение ошибок разметки и повышение разнообразия набора данных.

Работа частично поддержана рамочной программой ЕС Horizon Europe по соглашению № 101135724 (LUMINOUS).
